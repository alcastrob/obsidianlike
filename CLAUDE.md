## What this is

A minimal VS Code extension (`.vsix`) that acts as a local Obsidian-like vault tool. It operates entirely offline — no marketplace, no external servers. The extension is installed locally from a `.vsix` package.

Two commands are registered:
- `vaultTool.listNotes` — recursively scans the open workspace folder for `.md` files and lists them in the Output panel.
- `vaultTool.openKanban` — opens a Webview panel (currently a placeholder for Kanban/Eisenhower logic).

## Commands

```bash
# Install dependencies
npm install

# Compile TypeScript to out/
npm run compile

# Watch mode (recompiles on save)
npm run watch

# Package as .vsix (requires @vscode/vsce installed globally)
vsce package

# Install locally
code --install-extension vault-tool-0.0.1.vsix
```

## Development workflow

Press **F5** in VS Code/Windsurf to launch an Extension Development Host — no packaging needed. In the second window, open a vault folder, then run commands via the Command Palette (`Ctrl+Shift+P`).

## Architecture

- `src/extension.ts` — the entire extension: `activate()` registers both commands, `deactivate()` is a no-op.
- `out/` — compiled JS (generated by `tsc`, gitignored pattern; required before packaging).
- The extension has **no runtime npm dependencies** — only `devDependencies` for TypeScript and VS Code type definitions.
